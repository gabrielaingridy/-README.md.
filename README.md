Sistema de Gestão de Biblioteca 

Objetivo
O projeto visa digitalizar e automatizar o controle de uma biblioteca, substituindo os registros em papel e planilhas isoladas. O sistema organiza o catálogo de livros, gerencia empréstimos e devoluções, mantém o histórico de transações seguro e automatiza cobranças por atraso.

Usuários (Stakeholders)
Bibliotecários:Responsáveis por gerenciar o catálogo, registrar empréstimos, devoluções e novos usuários.
Leitores (Alunos, Professores ou Comunidade):Usuários que realizam os empréstimos e consultam o acervo.
Administradores:Responsáveis por gerir o sistema de forma geral e acessar relatórios/configurações.

Funcionalidades Iniciais
- Cadastro de novos livros e leitores.
- Registro de empréstimos e devoluções de livros.
- Pesquisa de livros disponíveis no catálogo por título ou autor.
- Cálculo automático de multas para livros devolvidos com atraso.
